# Portfolio

A modern, responsive portfolio website built with React, featuring 6 different pages to showcase your skills, experience, and projects.

## Features

- **Landing Page** - Impressive hero section with call-to-action buttons
- **Skills & Experience** - Showcase your professional skills
- **Tech Stack** - Display technologies and tools you use
- **Experience** - Highlight your work history
- **Projects** - Showcase your portfolio projects with descriptions and tech tags
- **Contact** - Contact form and social media links

## Tech Stack

- **React 18** - UI library
- **React Router DOM** - Client-side routing
- **Vite** - Build tool and dev server
- **CSS 3** - Styling with gradients and modern effects

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open [http://localhost:5173](http://localhost:5173) in your browser

## Building for Production

```bash
npm run build
```

The optimized production files will be in the `dist/` directory.

## Customization

Update the content in the page components to match your information:

- `src/pages/Landing.jsx` - Your welcome message
- `src/pages/Skills.jsx` - Your skills
- `src/pages/TechStack.jsx` - Your technologies
- `src/pages/Experience.jsx` - Your work experience
- `src/pages/Projects.jsx` - Your projects
- `src/pages/Contact.jsx` - Your contact information

## Styling

All styles are in CSS files in the `src/` directory. The color scheme uses:
- Primary: #646cff (Blue)
- Secondary: #00d4ff (Cyan)
- Background: #0a0e27 (Dark Blue)
- Text: #e0e0e0 (Light Gray)

Modify the CSS files to customize colors and styling to your preference.

## Deployment

You can deploy this portfolio to platforms like:
